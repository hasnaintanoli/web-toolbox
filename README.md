# WebToolBox

A fast, privacy-first collection of useful web and developer utilities.

## Included tools

- JSON Formatter & Validator
- Base64 Encoder / Decoder
- URL Encoder / Decoder
- Color Converter
- UUID Generator
- Unix Timestamp Converter
- Text / Word / Character Counter
- Password Generator

## Tech

React 19 + Vite + Lucide Icons. No backend required — the tools run locally in the browser.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Built for practical everyday web development.
